# Zabbix Item Grid Widget

## Опис (UA)
Потужний та гнучкий віджет для створення кастомних панелей моніторингу. Дозволяє групувати елементи даних у блоки, налаштовувати їх розмір (сітка з 10 колонок) та візуалізацію.

**Особливості:**
- Гнучка сітка: налаштування ширини та висоти кожного блоку.
- Вбудовані графіки-спарклайни для кожного айтема.
- Підтримка бінарних даних (UP/DOWN) та конвертація одиниць (B, Bps, s тощо).
- Повне налаштування кольорів фону, рамок та графіків.
- Drag-and-drop сортування елементів у налаштуваннях.

## Description (EN)
A powerful and flexible widget for creating custom monitoring dashboards. Allows you to group data items into blocks, customize their size (10-column grid), and visualization.

**Features:**
- Flexible grid: customize the width and height of each block.
- Built-in sparkline graphs for each item.
- Support for binary data (UP/DOWN) and unit conversion (B, Bps, s, etc.).
- Full customization of background, frame, and graph colors.
- Drag-and-drop sorting of items in settings.

## Встановлення / Installation
1. Завантажте файли репозиторію.
2. Скопіюйте папку в директорію `ui/modules/` вашого Zabbix.
3. Перейдіть в `Administration -> General -> Modules` та натисніть `Scan`.
4. Увімкніть модуль "Item Grid Widget".
